Set up your assistant

This is a personal daily-planning assistant that talks to Claude directly from your browser. To use it you'll need an Anthropic API key — add one in Settings to get started.

Enter to send · Shift+Enter for a new line

Settings

Your API key and data are stored only in this browser's local storage — never sent anywhere except directly to Anthropic's API when you send a message.

Get one at console.anthropic.com → API Keys. Usage is billed per request on your Anthropic account.
Defaults to Claude Haiku — the cheapest current model — to keep costs low for daily chat. Swap in claude-sonnet-5 for better quality at a higher price if you want. If a model name stops working, check platform.claude.com/docs for the current list.
Lets this app store your tasks, habits and chat in a private GitHub Gist and pull them in on every device where you paste the same token — no manual copying needed. Create one at github.com/settings/tokens → "Generate new token (classic)" → tick only the gist scope. Leave blank to keep this device local-only.
Off by default — your Anthropic key stays only on this device unless you turn this on. If on, it's stored in the same private Gist as everything else.
